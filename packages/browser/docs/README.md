# Nexum browser 手册

本包操作同设备已经连接的 Chromium 浏览器。先按 [连接说明](connection.md) 检查真实上线状态；没有在线浏览器时，不把离线当作空页面，也不自动启动另一个浏览器。

- [使用与结果交付](usage.md)：发现、观察、动作、验证、截图和未知结果处理。
- [连接与原生限制](connection.md)：匹配插件、profile、端口、重连、用户停止。
- [运行生命周期](lifecycle.md)：目标绑定、run 资源、锁和真正关闭。
- [公开接口与数据类型](api.md)：当前包声明、参数与返回值，可按接口名定位阅读。

完整可调用方法及输入 Schema 随当前 Agent 的受管方法表提供；普通客户端还提供不可变 Locator、Frame、Dialog、Download 门面。当前包没有注册的高阶方法返回明确不可用，不能因为客户端能构造一个门面就宣称后端已经实现。
