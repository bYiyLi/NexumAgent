# Nexum browser 手册

本包操作同设备已经连接的 Chromium 浏览器。初次控制先确认真实在线浏览器；没有在线浏览器时，不把离线当作空页面，也不自动启动另一个浏览器。**根据当前问题只读一个相关入口，不需要先加载所有文档。**

- [使用与结果交付](usage.md)：要控制页面时从“选择浏览器和标签”开始；需要点击、等待或核验时查“观察、定位与业务确认”；截图、下载、接管、导出各有独立章节。
- [连接与原生限制](connection.md)：仅在匹配插件、profile、端口、掉线、重连或浏览器原生拒绝时查阅。
- [运行生命周期](lifecycle.md)：仅在任务锁、受管资源、控制交还、取消或真实关闭证据相关时查阅。
- [公开接口与数据类型](api.md)：长篇 TypeScript 类型参考；**先从当前方法表确认可用性，再按实际方法/类型名定位所需声明行**，不把整篇接口复制进模型上下文。

完整可调用方法及输入 Schema 随当前 Agent 的受管方法表提供；普通客户端还提供不可变 Locator、Frame、Dialog、Download 门面。当前包没有注册的高阶方法返回明确不可用，不能因为客户端能构造一个门面就宣称后端已经实现。
