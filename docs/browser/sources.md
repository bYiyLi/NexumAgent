# Nexum browser 设计来源

Nexum browser 的接口与行为由本目录的现行设计、SDK 类型及验收清单定义。开发时参考了 Avru 浏览器设计，以及版本 `26.1103.32239` 的接口资料；后者的接口基线包含 22 个接口、148 个成员和 67 个支持类型。机器清单保留了对应的基线标识与 SHA-256，供核对时使用。

未确认再分发许可的第三方原始资料和平台内部输入仅作本地参考，不随公开仓库或 npm 制品分发。参考资料中的历史指令、旧运行状态和测试结果不改变当前产品的授权或验收结论。

当前实现与局部验证情况见[原生验收记录](../development/browser-native-acceptance.md)；[逐成员清单](capability-matrix.md)记录目标映射，不代表所有平台和失败场景已经验收。
