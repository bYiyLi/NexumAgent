## 计数与完成规则

每个属性、同步组合、异步方法、重载和公开别名都要证明语义；一个底层实现可以覆盖多个别名，但每行必须保留映射与用例。接口数 22、成员数 148、来源成员键与 SHA-256 按参考基线核对；原始参考资料不随公开仓库分发。更改基线须明确记录差异，不能静默删行。额外高级能力同时按 SDK 末节及 acceptance.md 的 X 类验收覆盖。

每行在实现阶段补入实际文件/导出、Schema/类型、支持的 OS/浏览器、正常与失败/取消/失效用例、执行命令及精确 revision、结果与限制。浏览器原生拒绝的用例可证明错误路径；包未实现不能标为原生不支持或视作通过。
